## 3. 核心新增：流动性执行层

### 3.1 问题

511010 国债ETF场内交易规则：最小交易单位 100 份，当前单价约 140 元/份，单次最低买入约 14,000 元。月投金额 ≤ 2万时，固收分配金额几乎永远 < 14,000 元，实盘无法执行。

### 3.2 解决方案：BondAccumulator

**文件**: `src/execution/bond_liquidity.py`

**类设计**:

```python
class BondAccumulator:
    """国债ETF虚拟累积池——解决场内最低买入门槛问题。"""

    def __init__(self, min_purchase: float = 14000.0):
        self._balance: float = 0.0       # 累积池余额
        self._min_purchase: float = min_purchase
        self._total_interest: float = 0.0  # 累计逆回购收益

    def deposit(self, amount: float) -> None:
        """每月固收应配金额入池。"""
        self._balance += amount

    def accrue_interest(self, annual_rate: float = 0.018) -> float:
        """按月累积逆回购收益（年化1.8%，月化 = 年化/12）。"""
        monthly_rate = annual_rate / 12
        interest = self._balance * monthly_rate
        self._balance += interest
        self._total_interest += interest
        return interest

    def execute(self) -> BondAction:
        """判断是否触发买入。"""
        if self._balance >= self._min_purchase:
            lots = int(self._balance // self._min_purchase)
            buy_amount = lots * self._min_purchase
            self._balance -= buy_amount
            return BondAction(buy=True, lots=lots, amount=buy_amount)
        return BondAction(buy=False, lots=0, amount=0.0)

    def get_status(self) -> dict:
        """报告层用的状态快照。"""
        return {
            "balance": self._balance,
            "min_purchase": self._min_purchase,
            "total_interest": self._total_interest,
            "can_buy": self._balance >= self._min_purchase,
            "lots_available": int(self._balance // self._min_purchase),
        }


@dataclass
class BondAction:
    buy: bool
    lots: int
    amount: float
```

**调用顺序（每月）**:

```
1. accumulator.deposit(bond_amount)      # 分配层输出的固收金额入池
2. interest = accumulator.accrue_interest()  # 计算逆回购收益
3. action = accumulator.execute()        # 判断是否触发买入
4. 如果 action.buy: 记录买入 511010
5. 如果 !action.buy: 余额计入"现金+逆回购"，不计入固收持仓
```

### 3.3 回测集成

`backtest/engine.py` 中的修改：

### 3.5 持久化（流A跨月保存）

流A（`run.py report`）每月独立运行一次，累积池余额必须跨月保存。

**方案**: JSON 状态文件 `data/db/bond_accumulator.json`

```json
{
  "balance": 3000.0,
  "total_interest": 8.50,
  "last_update": "2026-07-01"
}
```

**BondAccumulator 新增方法**:

- `save(path)` — 将余额和累计收益写入 JSON
- `load(path) → BondAccumulator` — 从 JSON 恢复状态（类方法）

**调用时机**:
- `run.py report` 开头：`accumulator = BondAccumulator.load(path)`
- `run.py report` 结尾：`accumulator.save(path)`

**回测中不需要持久化**——单实例贯穿全程，无需读写文件。
