## 一、设计哲学

### 1.1 核心问题
每月有一笔新钱（如1万），分配到几个ETF和债券上。三个难点：
- **时机问题**：有些资产贵，有些便宜，不能闭眼平均分
- **组合问题**：每次决策局部合理，长期可能导致某个资产占比失控
- **心理问题**：市场狂热时不敢买，恐慌时不想买，系统帮你扛住情绪

### 1.2 设计约束
- 每月只做一次决策，不盯盘
- 默认不卖（减少交易成本和心理负担），保留年度再平衡
- 最多6-8个资产，因子不超过每资产2个
- 每个决策可追溯到具体数据和规则
- 严格禁止未来信息泄漏


## 二、全局架构：两条数据流

**流A（运行流）**：每月执行的分配流程，只执行不调参。

**流B（验证流）**：离线回测，训练期调参→锁死参数→测试期验证。

**关键纪律**：流A参数永远从流B的测试期结果中产生，绝不直接在流A里调。


## 三、资产池设计

| 资产 | 类别 | 跟踪指数 | 主因子 |
|------|------|----------|--------|
| 白酒ETF | 价值 | 中证白酒 | PE分位 |
| 银行ETF | 价值/红利 | 中证银行 | PB分位+股息率 |
| 红利ETF | 红利 | 中证红利 | 股息率分位 |
| 沪深300ETF | 宽基 | 沪深300 | PE分位 |
| 科创50ETF | 成长 | 科创50 | 动量+趋势 |

**卫星仓位**：如机器人ETF等主题资产，上限5%，不走评分体系，纯手动判断。

## 五、因子层

### 设计原则
- 每个资产最多2个因子
- expanding window计算，只用当日及之前数据
- 风险因子不进评分，单独输出

### 各资产因子定义

**白酒ETF**：PE滚动历史分位（5年窗口，expanding）

**银行ETF**：
- PB滚动历史分位（5年窗口）
- 股息率滚动历史分位（5年窗口）
- 合成：各算z-score，等权加权

**红利ETF**：股息率滚动历史分位（5年窗口）

**沪深300ETF**：PE滚动历史分位（5年窗口）

**科创50ETF**：
- 120日动量（过去120个交易日价格涨幅）
- 200日均线趋势开关（Price > MA200 → ON，否则 OFF）
- 趋势OFF时机会分减半（非归零，保留反转参与权）


## 六、评分层

各资产机会分计算：

| 资产 | 公式 |
|------|------|
| 白酒 | 机会分 = 1 - PE分位 |
| 银行 | PB_zscore + 股息_zscore 等权 → sigmoid |
| 红利 | 机会分 = 股息率分位 |
| 沪深300 | 机会分 = 1 - PE分位 |
| 科创50 | 机会分 = 动量分位 × (趋势ON ? 1 : 0.5) |


## 七、市场温度计（行为风控，非择时）

### 指标
- 主：沪深300 PE滚动分位（5年）
- 辅：全A等权 PB滚动分位（5年）

### 规则
| 条件 | 权益比例 | 固收比例 |
|------|---------|---------|
| 双指标均 < 60% | 100% | 0% |
| 双指标均 60%-80% | 70% | 30% |
| 双指标均 80%-90% | 40% | 60% |
| 双指标均 > 90% | 30% | 70% |
| 双指标不一致 | 维持上期比例 | — |

| 银行 | 30% | 25% | 60日波动率 > 年化25% |
| 红利 | 25% | 20% | 60日波动率 > 年化25% |
| 沪深300 | 30% | 25% | 60日波动率 > 年化30% |
| 科创50 | 15% | 10% | 60日波动率 > 年化40% |


## 九、组合约束层

### 单资产约束
| 资产 | 下限 | 常态上限 |
|------|------|---------|
| 白酒 | 10% | 25% |
| 银行 | 10% | 30% |
| 红利 | 10% | 25% |
| 沪深300 | 10% | 30% |
| 科创50 | 5% | 15% |
| 固收 | 10% | 20% |

### 因子组约束
| 因子组 | 包含资产 | 上限 |
|--------|---------|------|
| 价值+红利 | 白酒+银行+红利+沪深300 | 60% |
| 成长 | 科创50 | 15% |
| 防御 | 固收 | 20% |

### 惩罚函数（平滑，防跳变）
```
可买入系数 = 1                    （当前权重 < 上限-5%）
可买入系数 = (上限-当前权重)/5%   （上限-5% ≤ 当前权重 < 上限）
可买入系数 = 0                    （当前权重 ≥ 上限）
```

### 综合上限
```
最终仓位上限 = min(单资产上限, 因子组剩余空间, 风险层调整后上限)
```


## 十、资金分配层

### 输入
- `new_money`：本月新增资金
- `invest_ratio`：温度计输出的权益投资比例
- → 可投权益 = new_money × invest_ratio
- → 进固收（理论值）= new_money - 可投权益

### 分配算法

**步骤1：计算缺口分**
```
缺口分 = 目标权重下限 - 当前实际权重
如果所有缺口分 ≤ 0 → 跳过缺口调整，直接按机会分分配
缺口分归一化到 [0,1]
```

**步骤2：综合优先级**
```
综合优先级 = 0.5 × 缺口分 + 0.5 × 机会分
```

**步骤3：按优先级分配**
```
分配金额 = 该资产最终上限对应金额 - 当前持仓金额
如果分配金额 ≤ 0，跳过
如果分配金额 > 剩余可投权益，分配 = 剩余可投权益
```

**步骤4：剩余资金**
```
所有权益资产到上限后仍有剩余 → 进入固收
```


## 🔴 十一、流动性执行层（V1.2新增——解决国债ETF门槛问题）

### 11.1 问题定义

策略输出的固收分配金额是理论值，但511010国债ETF场内交易规则：
- 最小交易单位：100份
- 当前单价：约140元/份
- **单次最低买入金额：约14,000元**

月投金额在2万以下时，固收分配金额（通常0~7,000元）几乎永远小于14,000元，实盘无法执行。

### 11.2 解决方案：虚拟累积池（Bond Accumulator）

**核心机制**：每月固收应配金额累加到虚拟池中，攒够14,000元才触发一次买入。

```
每月执行：
  bond_alloc = 分配层输出的固收金额
  bond_accumulator += bond_alloc

  if bond_accumulator >= 14,000:
      买入手数 = floor(bond_accumulator / 14,000)
      执行买入(511010, 手数)
      bond_accumulator -= 手数 × 14,000
  else:
      本月不操作，继续累积
```

### 11.3 配置项

```python
BOND_MIN_PURCHASE = 14000.0      # 单次最低买入金额
BOND_UNIT_SIZE = 100             # 最小交易单位（份）
BOND_EXECUTION_MODE = "ACCUMULATE"  # 累积制（推荐）
# 备选模式："ALTERNATIVE" → 替换为场外短债/同业存单
# 备选模式："SKIP" → 不够则不买（不推荐）
```

### 11.4 回测模拟

回测中必须维护`bond_accumulator`全局变量，每月累加并判断是否触发买入。严禁将未达门槛的小额资金按"已买入固收"计算收益。

### 11.5 现金管理

累积池中的闲置资金在账户中体现为可用资金，可参与**场内逆回购（如GC001）**获取额外收益：
- GC001为1天期国债逆回购，1000元起，T+1日资金自动可用
- 不影响ETF买入计划，纯粹是闲置资金生息
- 季末/年末利率飙升时收益可观


## 十二、年度再平衡

### 触发条件
每年12月第一个交易日，检查各资产实际权重。

### 目标权重（取上下限中点）

| 资产 | 下限 | 上限 | 目标（中点） |
|------|------|------|-------------|
| 白酒 | 10% | 25% | 17.5% |
| 银行 | 10% | 30% | 20% |
| 红利 | 10% | 25% | 17.5% |
| 沪深300 | 10% | 30% | 20% |
| 科创50 | 5% | 15% | 10% |
| 固收 | 10% | 20% | 15% |

### 规则
```
如果 |实际权重 - 目标权重| > 10个百分点：
    触发该资产的再平衡
    卖到目标权重偏离5%以内（留缓冲，不追求精确归位）
```


## 十三、回测引擎（流B）

### Point-in-Time约束
回测在日期T决策时：
- 价格/估值数据：仅用 `trade_date ≤ T` 且 `publish_date ≤ T` 的数据
- 分位计算：仅基于 `date ≤ T` 的历史数据（expanding，上限5年窗口）
- 指数回填段（base_date ~ publish_date）：打标，回测时选择性使用

### 训练/测试分离
```
数据时间轴：2015-01-01 到 2025-12-31
→ 训练期：2015-01-01 到 2021-12-31（调参用）
→ 测试期：2022-01-01 到 2025-12-31（锁死参数验证）
```

### 评价指标
- 年化收益率
- 最大回撤
- **Calmar比率**（核心）：年化收益/最大回撤
- 夏普比率
