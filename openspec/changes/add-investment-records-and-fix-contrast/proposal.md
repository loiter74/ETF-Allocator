## Why

原前端的暗色偏好会与大量为浅色模式写死的文字颜色组合，导致深色卡片上出现低对比度甚至不可见文本。同时，系统没有记录真实追加投入，用户无法确认上次投入日期、金额与累计投入。

## What Changes

- 将现有 Dashboard 锁定为原设计的统一浅色主题，清除会触发不完整暗色模式的历史偏好，并保证卡片、导航和表单文字可读。
- 新增持久化的投入记录，记录投入日期、金额和可选备注。
- 每条投入记录保存六个 ETF/国债资产的分项金额，总额由明细自动汇总。
- 新增投入记录查询与创建 API，并对输入进行日期、金额和重复记录校验。
- 在原导航中增加“资金记录”页面，展示最近一次投入、累计投入、记录次数和历史明细。
- 允许用户手动录入以往投入；模拟计算不会自动生成真实投入记录。
- 移除与本月概览功能重叠的“持仓模拟”页面和导航入口，旧链接返回本月概览。

## Capabilities

### New Capabilities

- `investment-records`: 真实追加投入及各资产分项金额的持久化、API、手动历史录入、汇总与列表展示。

### Modified Capabilities

- `dashboard-ui`: 导航保留本月概览、历史趋势和资金记录三个页面，并明确原浅色设计下的对比度与可读性要求。

## Impact

- 后端 SQLite schema 与 FastAPI `src/api/server.py` 增加投入记录表和 API。
- 前端增加资金记录类型、hook、页面与路由，并调整 NavBar。
- 前端移除独立持仓模拟页面，避免与本月概览重复。
- 主题初始化改为统一浅色模式，不再激活未完整实现的暗色模式。
- 增加后端 API 测试、前端单元测试和页面回归验证。
