## ADDED Requirements

### Requirement: 月报展示国债执行状态
月度报告 SHALL 在【本月新增资金】和【权益分配】之间展示"国债执行状态"区块，包含：本月固收应配金额、累积池存量（含逆回购收益）、累积池总额、是否触发买入、买入后余留金额。

#### Scenario: 触发买入时的展示
- **WHEN** 本月固收应配 ¥3,000，累积池存量 ¥14,000（含逆回购收益 ¥126），触发买入1手
- **THEN** 报告显示：
  ```
  【国债执行状态】（模式：累积制）
  本月固收应配： ¥3,000
  累积池存量：   ¥14,000（含逆回购收益 ¥126）
  累积池总额：   ¥17,000
  → 本月操作：   ✅ 买入 1 手 511010（¥14,000）
  买入后余留：   ¥3,000（自动滚入下月）
  ```

#### Scenario: 未触发买入时的展示
- **WHEN** 本月固收应配 ¥3,000，累积池存量 ¥5,000（含逆回购收益 ¥8），未触发
- **THEN** 报告显示：
  ```
  【国债执行状态】（模式：累积制）
  本月固收应配： ¥3,000
  累积池存量：   ¥5,000（含逆回购收益 ¥8）
  累积池总额：   ¥8,000
  距下一手门槛： ¥6,000（需 ¥14,000 触发）
  → 本月操作：   ⏳ 暂不买入，继续累积
  ```

### Requirement: 逆回购收益独立展示
月报 SHALL 将逆回购收益在"累积池存量"中以括号形式展示（"含逆回购收益 ¥X"），不混入固收持仓收益。

#### Scenario: 逆回购收益展示
- **WHEN** 累积池累计逆回购收益为 ¥45.30
- **THEN** 报告中"累积池存量"行显示"含逆回购收益 ¥45"
